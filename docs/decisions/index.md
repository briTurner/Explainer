# Decisions

Decision pages record protocol choices, rationale, and alternatives.

They are intentionally separate from reference pages. Reference pages describe the current contract; decision pages explain why the contract is taking that shape.

Decision records use a light ADR-style structure: Status, Context, Decision, and Consequences. Reversed or replaced decisions should not be deleted. Mark them `Superseded`, link to the replacement decision, and leave the old rationale intact.
